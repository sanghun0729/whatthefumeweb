# Fume Cursor Trail — 마우스 향(fume) 트레일 이펙트

WHAT THE FUME 브랜드용 PC 마우스 커서 이펙트입니다.
커서를 움직이면 **와인빛 향(fume)이 부드럽게 피어올랐다 사라지는** 절제된 연출을 합니다.

## 브랜드 근거

| 요소 | 값 | 근거 |
|---|---|---|
| 컬러 | 와인 `#7c1836`, 진주빛 코어 `#f5ebee` | 브랜드 3색(wine/white/black) 준수 |
| 모티프 | 피어오르는 향/잔향 | 브랜드명 "FUME" 직결 |
| 모션 | 느린 상승·확산·페이드 | "slow motion / 200ms base" 톤 |
| 밀도 | 최대 불투명도 0.11~0.17 | "restraint / 절제" 원칙 |

## 특징

- **PC 전용**: 마우스(`pointer:fine`) 환경에서만 동작. 모바일·터치에서는 자동 비활성.
- **접근성**: `prefers-reduced-motion` 설정 사용자에겐 자동으로 꺼짐.
- **클릭 방해 없음**: `pointer-events:none` — 버튼/링크/스크롤을 막지 않음.
- **성능 보호**: DPR 상한 2, 파티클 상한 120개, `requestAnimationFrame` 단일 루프.
- **의존성 0**: 외부 라이브러리 없음. 순수 HTML+CSS+JS 한 덩어리.

## 미리보기

`demo.html` 을 브라우저로 열고 커서를 움직여 보세요.
화이트 / 와인 / 블랙 세 배경에서 어떻게 보이는지 한 페이지에서 확인할 수 있습니다.

## cafe24 적용 방법

1. cafe24 관리자 접속 → **디자인(PC) → 디자인 관리 → 디자인 편집(스마트디자인)**
2. 모든 페이지 공통으로 넣으려면 **레이아웃** HTML을 엽니다.
   (헤더/푸터가 포함된 공통 레이아웃 파일)
3. `snippet.html` 의 내용 **전체를 복사**해서, 레이아웃의 **`</body>` 태그 바로 위**에 붙여넣습니다.
4. 저장 후 실제 PC 브라우저에서 커서를 움직여 확인합니다.

> 특정 페이지(예: 메인)에만 넣고 싶다면 해당 페이지 모듈의 하단에 붙여넣어도 됩니다.

## 커스터마이징 (원하면 수치만 조정)

`snippet.html` 안에서:

- **진하기(절제/강조)**: `peak:0.11 + Math.random()*0.06` 의 숫자를 키우면 더 진해집니다.
- **양(밀도)**: `spawn(... , count)` 및 `MAX` 값 조정.
- **상승 속도**: `vy` 의 `-0.25 - Math.random()*0.45` 값을 조정.
- **레이어 순서**: CSS `z-index:9998` 를 테마 헤더보다 낮게/높게 조정.
- **끄기**: 이 코드 블록만 삭제하면 됩니다.
